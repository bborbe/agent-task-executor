<summary>
- Every agent Config can now declare a target namespace for its Jobs.
- An unset target namespace means "the executor's own namespace", so every existing Config keeps behaving exactly as it does today and the executor deploy is a no-op.
- A Config that explicitly names the executor's own namespace is rejected by a small pure rule, so no Config can be written to opt out of isolation.
- The executor's own Kubernetes schema declares the new field, so the API server does not silently prune it (the v0.5.0 `maxConcurrentJobs` failure cannot repeat).
- The value survives the resolver: a Config with the field set reaches the spawner with the field set, and an unset field reaches it empty.
- Two Configs that differ only in this field are now correctly detected as different.
- New tests pin the default resolution, the rejection rule, the resolver round-trip, the schema entry and the JSON tag.
- No namespace, policy, RBAC or manifest is created here — that stays in the `bborbe/agent` chart.
</summary>

   ```go
   package pkg

   import (
       "context"

       "github.com/bborbe/errors"
       libk8s "github.com/bborbe/k8s"
   )

   // ResolveJobNamespace returns the namespace in which a Config's Jobs must be
   // created. An empty jobNamespace means the executor's own namespace, preserving
   // the behaviour of every Config that does not set the field. A jobNamespace
   // equal to the executor's own namespace is rejected: that would be an explicit
   // opt-out of isolation, and no Config may author one.
   func ResolveJobNamespace(
       ctx context.Context,
       executorNamespace libk8s.Namespace,
       jobNamespace string,
   ) (libk8s.Namespace, error) {
       if jobNamespace == "" {
           return executorNamespace, nil
       }
       if jobNamespace == executorNamespace.String() {
           return "", errors.Errorf(
               ctx,
               "jobNamespace %q may not equal the executor namespace",
               jobNamespace,
           )
       }
       return libk8s.Namespace(jobNamespace), nil
   }
   ```
   The error text MUST contain the exact substring `may not equal the executor namespace`.
